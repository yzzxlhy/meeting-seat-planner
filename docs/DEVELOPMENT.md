# 会务席位图 · 开发与设计说明

面向开发者的重构记录与设计取舍。使用说明请看根目录 [`README.md`](../README.md)。

单文件 HTML 工具：拖拽排座、团体标注、缺席递补、PNG / CSV / 文本导出。
双击 `dist/会议辅助.html` 即用，**无外部依赖、无网络请求、无 CDN**。

---

## 1. 快速使用

| 想做的事 | 操作 |
|---|---|
| 改规模 | 左栏「每排座位数」填 `10,10`，回车 |
| 加过道 | 「过道位置」填 `5`（第 5 座后一条过道） |
| 排座 | 左栏贴名单 → 「应用名单并排座」 |
| 交换两人 | 把座位拖到另一个座位上 |
| 插入到某位置 | 拖到座位之间的空隙，松手后顺位后移 |
| 填名 / 改名 | 点空位填名；点座位左上 ✎ 改名 |
| 标记缺席 | 点有人座位；下方「缺席」标签点一下即插回原位 |
| 单位 | 点座位里的单位文字，Enter 换行（最多 3 行），Ctrl+Enter 保存 |
| 团体 | 「标注团体区域」→ 点选座位 → 选色 + 填团名 → 完成 |
| 字号 | 团名 / 单位 / 姓名 三组独立 −/+，PNG 同步 |
| 字体 | 「字体搭配」下拉：公文（宋体标题+雅黑正文）/ 全宋 / 黑体 / 楷体，即时切换，PNG 同步 |
| 出图 | 「导出 PNG」（2 倍图）/「打印」（自动隐藏工具栏，只出图面与座次表） |
| 座号 | 「隐藏座号」/「显示座号」一键切换，图面与 PNG 同步 |
| 中轴线 | 「隐藏中轴线」/「显示中轴线」一键切换，图面与 PNG 同步 |
| 数据 | 「导出 CSV」Excel 可开；「复制文本」贴微信；「保存到本机」存浏览器 |

## 2. 目录结构

```
│   └── main.js         # 交互层：事件、动作、存档、导出

│   ├── DEVELOPMENT.md  # 本文件
│   └── screenshots/    # README 用的界面与导出图
├── test_ui.py          # 主流程交互测试（Playwright）
├── test_features.py    # 功能回归清单
├── test_migration.py   # 旧版存档迁移
├── test_fonts.py       # 字体方案与 PNG 刊头
├── test_scenes.py      # 场景切换与长桌几何
├── audit_layout.py     # 几何排版审计（溢出 / 中轴对位 / 移动端）
├── check_contrast.py   # WCAG 对比度体检（读运行时令牌）
├── inspect_png.py      # 导出 PNG 的像素体检
└── make_shots.py       # 重新生成 README 截图
```

构建：

```bash
python build.py          # 产物 dist/会议辅助.html（docs/ 存在时同步 docs/index.html）
```

运行全部校验：

```bash
python test_ui.py && python test_features.py && python test_migration.py && python test_fonts.py && python test_scenes.py
python audit_layout.py && python check_contrast.py && python inspect_png.py
```

## 3. 相比 v1 改了什么

### 3.1 结构：一份渲染逻辑，两种出口

v1 在 `render()` 里按「团体 / 选中 / 有人 / 空位」写了四份近似重复的分支，
每份各自拼 `innerHTML`、各自绑 `×` 按钮、各自绑拖拽。

v2 把它收敛为：

```
seatModel(idx)  →  { 行/字号/团名行/单位行/墨色/是否空位 }
      ├─ buildSeat()    → DOM（单一构造器，无分支复制）
      └─ exportPNG()    → Canvas（消费同一份模型）
```

**屏幕与 PNG 不可能再漂移**：字号由同一个 `fitFontSize()` 用 `measureText` 实测得出，
v1 是 DOM 用字符宽度估算、Canvas 用 `measureText` 各算一遍。

### 3.2 修掉的 Bug

| 编号 | 问题 | 修法 |
|---|---|---|
| B1 | 中轴线靠 `querySelector('.num')` 找 1/2 号，团体座位没有 `.num` → 主席台与中轴静默失效 | 按 `data-seat` 取座位元素，用 `offsetLeft/offsetWidth` 计算 |
| B2 | 清空座位后人员仍留在 `people[]`，状态栏出现「未排座 1 人」幽灵 | `clearSeat()` 同步移除人员并重排索引引用 |
| B3 | 撤销只快照座位，团体增删改名无法撤销 | 快照扩为整份状态（人员/座位/单位/缺席/团体/布局/字号） |
| B4 | 缺席区用 `innerHTML` 直接插入姓名，含 `&`/`<` 破图并有注入面 | 全程 `textContent` 构造，产物中 `innerHTML` 出现次数为 0 |
| B5 | CSS 定义了 `.no-print` 但没有任何规则 → 打印会带出工具栏 | 补齐 `@media print`：隐藏左栏与工具栏，保留图面与座次表 |
| B6 | CSV 未转义逗号/引号，姓名含 `,` 即列错位 | 标准 CSV 转义（`"` 双写） |
| B7 | 空隙插入按「列号」解释，而座次是中心散开的，标签与实际结果错位 | 空隙归属「右侧那个座位」，按座号解释，标签写明「在 N 号前插入」 |
| B8 | 双击改名与单击「标记缺席」冲突：双击会先触发一次缺席 | 改为左上角 ✎ 改名，双击不再绑定动作 |

### 3.3 工程化

- **三文件分层**：state（纯函数）/ view（渲染）/ main（交互），职责不重叠。
- **常量集中**：几何、字号上下限、行数上限、历史深度、存储键，无魔法值。
- **设计令牌单一来源**：`PALETTE`/`FONTS`/`GEO` 由 JS 注入 CSS 变量，
  CSS 与 Canvas 读同一份值，改一个色不用改两处。
- **移动端可用**：拖拽改为 Pointer Events（鼠标 + 触摸同一套实现，v1 只有 HTML5 DnD，触屏完全不可用）；
  `html/body` 加 `overflow-x: clip`，横向滚动只发生在图面容器内。
- **无障碍**：座位是 `role=button` + `tabindex=0` + `aria-label`；
  方向键移动焦点，Enter 编辑，Delete 清空；`:focus-visible` 有明确焦点环。
- **存档兼容**：默认读 v30，找不到则回退读取 v28 旧档并迁移（排数/过道/人员/单位/团体/字号偏移）。
- **打印样式**：Ctrl+P 直接得到可发的纸质席位图。

### 3.4 视觉（Hallmark · Workbench + 公文/图纸体裁）

- 结构：左「编制」索引栏 + 右「图面」+ 右下角标题栏（会议名称 / 日期 / 席位 / 出席 / 缺席）。
- 主题：Custom —— 纸白 `#F4F1EA` + 墨黑 `#1A1814` + 朱砂 `#9C3B2E`；宋体标题、雅黑正文、等宽数字。
- 纪律：无投影、无渐变装饰、不重画假浏览器/手机外壳；层级靠字号、字重、发丝线。
- 对比度：正文 15.7:1，注脚 5.0:1，团色白字 ≥ 5.3:1，全部达到 WCAG AA。

### 3.5 v3 调整（本轮）

- **字体可选**：新增「字体搭配」下拉，4 种组合（公文体 / 全宋 / 黑体 / 楷体），
  切换即时生效、与 PNG 导出同步、随存档保存。字族全部为系统自带，不联网加载字体。
- **去掉统计**：移除「总席位 / 已就座 / 空位 / 缺席 / 未排座」统计条；
  标题栏精简为「会议名称 / 日期 / 席位构成」，PNG 页脚统计行一并删除。
- **修 PNG 刊头压线**：标题基线由实测字盒（`actualBoundingBoxAscent/Descent`）推算，
  副标题与分隔线随之下移，不再靠固定 y 值拍脑袋。
- **打包加固**：`build.py` 读取源文件时吞掉 BOM（PowerShell 写文件会带 BOM，
  会让 `:root` 整条规则失效、左侧栏塌成单列）。

### 3.6 印面只留已填内容（本轮）

屏幕上必要的编辑提示，不该跟着进纸面：

- **打印**：空位提示（`+ 填名` / `+ 单位` / `（空）`）、座次表的「操作」列、
  标题栏的「（未填写）」、图例（含「空位（点击填名）」）全部 `display:none`，
  空座只留虚线框与座号。
- **PNG**：不再绘制「空位」「（空）」「（未填写会议名称）」；空座保留虚线框与座号，
  团体内空位只留团色块与团名。
- **屏幕不受影响**：提示文字、悬停显形的「+ 单位」、操作按钮照旧，只在两个输出口收敛。
- **回归**：`test_ui.py` 增加「打印面不含未填占位」与「PNG 不含未填占位」两项断言
  （后者用 `fillText` 探针枚举实际绘制的文本）。

### 3.7 座号开关（本轮）

- 工具条新增「隐藏座号 / 显示座号」，决定座位左上角的座号。
- 单一开关输出三处：由 `seatModel().showNumber` 决定，DOM 不建 `.num` 节点、
  Canvas 不画座号，因此屏幕、打印、PNG 不可能不一致。
- 属显示偏好：随存档持久化，但**不进撤销链**（撤销只回滚数据）；旧存档缺字段时默认显示。

### 3.8 中轴线开关（本轮）

## 4. 设计口径备忘

- 座号规则：奇数座 1 号居中、2 号在左、3 号在右；偶数座中轴落在 1、2 号之间。
- 字号自适应：先求「盒子装得下的最大字号」，再叠加用户 −4~+4 的偏移；
  偏移导致超宽时按 `overflow: hidden` 优雅截断（不撑破座位、不影响导出）。
- 团长名多行：最多 3 行，Enter 换行；团名块占剩余高度并垂直居中。
- 单位多行：最多 3 行，宽度优先收缩，最低 4px；排版固定为「单位在上、姓名在下」
  （单位通常比姓名长，放上面不挤名字），DOM 与 Canvas 同一顺序。

### 3.9 场景框架与长桌（本轮）

- 新增 `S.scene` 与 `S.layouts`：每个场景独立存参数，`S.layout` 仍指向剧院式以兼容旧代码。
- `sceneSeatCount()` / `sceneGroups()` 成为座位总数与分组的唯一来源，座次表、CSV、TXT 全部改读它。
- 切场景时 `remapSeatsForScene()` 按「人 → 座位」重映射：单位跟人走、缺席与团体按人重算，座位不够则留作未排座。
- 剧院式仍走行式 DOM（`.row` / 空隙 / 过道），长桌走 `scenes.js` 的绝对坐标；两条路径共享 `buildSeat()` 与 `paintSeatCard()`。
- 长桌四边计数决定桌板形状：仅左右/仅上下 → 一整张桌；其余按有人的边画分段桌板，自然形成 U 型 / 回字。
